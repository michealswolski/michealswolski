I build defensive tools and simulations for connected vehicles, embedded software, and AI systems. My work focuses on making security decisions easier to verify, from firmware trust and software inventory to detection and human approval.

[Portfolio](https://michealswolski.github.io/) · [LinkedIn](https://www.linkedin.com/in/michealwolski/)

## Selected projects

- **[Automotive ECU Cybersecurity Lab](https://github.com/michealswolski/Automotive-ECU-Cybersecurity-Lab-)** · Simulation-first labs for automotive product security. The repository separates the implemented secure-boot simulator from planned modules such as message authentication and publishes its acceptance criteria. No vehicle or hardware validation.
- **[AutoSBOM Sentinel](https://github.com/michealswolski/AutoSBOM-Sentinel)** · Embedded Linux software inventory, human-reviewed vulnerability applicability, and runtime drift checks against a signed baseline.
- **[AI Agent Governance Dashboard](https://github.com/michealswolski/ai-agent-governance)** · A self-hosted review queue for agent traces, with risk scoring, human approval, and an auditable decision history.
- **[Splunk SIEM Lab](https://github.com/michealswolski/splunk-siem-lab)** · A documented lab covering log searches, alert triage, and investigation workflows.
